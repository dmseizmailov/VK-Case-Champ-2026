# VK CaseChamp 2026 · От пустой витрины до оплаты

[Открыть анализ с графиками](VK_CaseChamp.ipynb)

В выполненном ноутбуке показаны результаты за сентябрь 2026 года.

- Магазины с каталогом от 100 активных товаров получают заказ через чекаут в 13,1 раза чаще магазинов с 1–5 товарами.
- 85,7% рекламных расходов товарной выборки приходится на сообщества с нулём заказов через чекаут.
- Отношение нажатий к открытиям карточки составляет 3,1% у Маркета и 42,2% у партнёра. Из оформленных заказов Маркета 1,2% оплачены внутри VK.

- При ставке 3% увеличение доли оборота через VK Pay на 10 п. п. даёт 4,7 млн ₽ дополнительной месячной комиссии при сентябрьском GMV.

[Четыре графика в PNG](charts/)

Графики, правила отбора, код и выводы сохранены в ноутбуке. Для просмотра откройте его на GitHub. Для повторного запуска поместите исходный Excel организаторов в `data/Датасет.xlsx`, выполните команды ниже и запустите все ячейки.

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
jupyter lab VK_CaseChamp.ipynb
```

Расчёты выполнены в pandas, графики построены в Plotly. В каждой секции можно отдельно запустить расчёт и визуализацию. При просмотре на GitHub доступны сохранённые изображения. Для пересборки изображений Kaleido использует Chrome. При необходимости установите его командой `plotly_get_chrome`. Для работы только с интерактивными графиками в Jupyter выберите `EXPORT_PNG = False`.
